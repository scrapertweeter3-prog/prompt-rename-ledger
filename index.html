Seven candidates, three evals: pricing a prompt rename

A planner prompt edit looks like a one-file change. In the five-component support pipeline from the PastAGI worked example, router, planner, retriever, tool caller, synthesizer, the ledger says otherwise. Renaming one field in the planner output reaches all four downstream components through five edge classes: output-schema consumption, shared system prompt blocks, tool descriptions, retrieved few-shot pools, and context budgets. The traversal over those edges returns seven candidates, and seven is the number the full-suite habit prices at fifteen.

The verdicts are the ledger. The changed planner itself: retest, schema conformance on the new output. Router and tool caller on the shared persona block: skip, the shared segment hash is unchanged and the edit was planner-local. Tool caller on the schema edge: retest, a renamed field is a breaking API change with no compiler to flag it. Retriever: skip, the renamed field is metadata and sampled traces show its input unchanged. Synthesizer: retest and fold in, because the end-to-end run is the only probe that reaches two hops out, and it carries the truncation assertion for the longer plans. Three evals cover all seven candidates, and every skip carries written reasoning a reviewer can audit.

The count math is where the habit loses. Five components times three evals each is fifteen runs in the rerun-everything policy; the graph returns three, an 80 percent cut. At four minutes a run that is 60 minutes per release against 12. Eight prompt releases a month makes it 480 minutes against 96: 6.4 hours back every month, 76.8 hours a year, $5,376 a year at a $70 blended rate. The graph work that buys it is an afternoon of joins over traces the pipeline already logs.

Two traps guard the savings. First-hop reach alone returns five of the seven candidates: both synthesizer rows sit two hops out, so a shallow traversal hides 29 percent of the coupling, including the end-to-end row that is the only second-order probe. And a cache hit inside the retest window grades completions from before the change, an eval gone green against the old behavior. The prompt version belongs in the cache key; one line closes the trap. Without it, the missed schema break surfaces the way the example opens: a Friday edit found by a Tuesday complaint, four days of silent breakage.

The five edge classes, the candidate verdicts, and the worked pipeline are the PastAGI prompt dependency graph method, and the rest of the eval-cost ledgers live at pastagi.com.
